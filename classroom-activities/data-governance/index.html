Data Governance

Hands-on case studies and lab walkthroughs covering enterprise data governance, metadata management, data quality, and OpenMetadata implementation.

Modules
01
Enterprise Data Governance Foundation
📄 Case Study: “RetailCorp: The Data Chaos Challenge”
Live

A mid-to-large global retailer with fragmented data and zero governance. Students act as consultants to design a governance org chart, build a business glossary, catalog datasets, define data domains, and enforce access policies. Includes an optional Databricks notebook walkthrough.

02
Data Quality & Metadata Management
🏦 Case Study: “GlobalTrust Bank: The Duplicate Records Crisis”
Live

A multinational bank suffering from duplicate customer records, missing data, and invalid balances. Students profile and clean data in Databricks, validate with Great Expectations, catalog metadata in OpenMetadata, define data lineage, and set retention policies.

Databricks Great Expectations OpenMetadata Data Quality Data Lineage Data Retention PII

03
Data Protection & Security
🏥 Case Study: “HealthSecure Inc. — Healthcare Data Breach”
New

A healthcare company with an uncontrolled breach of Protected Health Information. Students mask PII fields in Databricks using PySpark, configure RBAC and data sensitivity classification in OpenMetadata, author five HIPAA-aligned security policies, and produce a risk assessment with CFR citations.

Databricks OpenMetadata HIPAA PHI / PII RBAC Data Masking Risk Assessment
