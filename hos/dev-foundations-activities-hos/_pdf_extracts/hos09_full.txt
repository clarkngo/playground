Key Concepts 
In this HOS, we will learn about creating and Deploying a Function on the Azure platform. 
 
Azure Function 
Azure Functions are a serverless compute service offered by Microsoft Azure that enables developers to 
run event-driven code without having to explicitly provision or manage infrastructure.  
• 
The core idea behind serverless computing is that you don't have to provision, manage, or scale 
servers yourself. Azure handles all of that, so you can focus solely on writing your application 
logic.  
• 
Azure Functions are suitable for a wide variety of scenarios, including building serverless APIs by 
Creating RESTful endpoints for web and mobile applications. 
• 
Azure Functions are a powerful and cost-effective way to build and deploy serverless 
microservices, allowing you to focus on business logic and leverage Azure's automatic scaling 
and infrastructure management capabilities. They fit perfectly into an event-driven 
microservices architecture.

5. Change the “function_app.py” file. 
 
import logging 
import datetime 
import json 
import azure.functions as func 
 
app = func.FunctionApp(http_auth_level=func.AuthLevel.ANONYMOUS) 
 
@app.route(route="daysbetween", methods=["POST"]) 
def daysbetween(req: func.HttpRequest) -> func.HttpResponse: 
    logging.info('Function triggered.') 
 
    try: 
        req_body = req.get_json() 
         
        start_date = req_body.get('start_date') 
        end_date = req_body.get('end_date') 
 
        if not start_date or not end_date: 
            return func.HttpResponse( 
                "Please provide both 'start_date' and 'end_date' in YYYY-MM-DD format.", 
                status_code=400 
            ) 
 
        # Parse the dates with specific error handling 
        try: 
            start_date_obj = datetime.datetime.strptime(start_date, '%Y-%m-%d').date() 
            end_date_obj = datetime.datetime.strptime(end_date, '%Y-%m-%d').date() 
        except ValueError: 
            return func.HttpResponse( 
                "Invalid date format. Please use YYYY-MM-DD.", 
                status_code=400 
            ) 
         
        days_between = abs((end_date_obj - start_date_obj).days) 
         
        response = {'days_diff': days_between} 
 
        return func.HttpResponse( 
            json.dumps(response), 
            mimetype="application/json", 
            status_code=200 
        ) 
 
    except ValueError: 
        return func.HttpResponse("Invalid JSON body.", status_code=400) 
    except Exception as e: 
        logging.error(f"Critical Error: {str(e)}") 
        return func.HttpResponse("An internal server error occurred.", status_code=500) 
 
Function Overview 
• 
Trigger: HTTP POST request to the /daysbetween route. 
• 
Input: JSON body with start_date and end_date in YYYY-MM-DD format. 
• 
Output: JSON response with the number of days between the two dates.
