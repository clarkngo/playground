A Dockerfile is essentially a text document containing all the instructions to build a Docker image. It

MySQL and MariaDB  
MySQL and MariaDB are both popular relational database management systems (RDBMS), but they 
have some differences.  
Origins: 
• 
MySQL: Developed by MySQL AB, later acquired by Oracle Corporation. 
• 
MariaDB: Created as a fork of MySQL by the original developers to ensure the database remains 
open-source after Oracle's acquisition. 
Licensing: 
• 
MySQL: Offers both open-source (under the GNU General Public License) and commercial 
versions. 
• 
MariaDB: Fully open-source under the GNU General Public License. 
Performance: 
• 
MariaDB: Often considered to have better performance and efficiency, with enhancements like 
the Aria storage engine. 
• 
MySQL: Known for its stability and widespread use, but some features are closed-source. 
Compatibility: 
• 
MariaDB: Designed to be a drop-in replacement for MySQL, meaning it uses the same data and 
table definition files, client protocols, and APIs. 
• 
MySQL: Continues to evolve with new features, some of which may not be compatible with 
MariaDB. 
Features: 
• 
MariaDB: Includes additional features like the Galera Cluster for synchronous multi-master 
replication. 
• 
MySQL: Offers features like the InnoDB storage engine, which is highly optimized for 
performance. 
Community and Support: 
• 
MariaDB: Strong community support with contributions from various developers. 
• 
MySQL: Backed by Oracle, with extensive documentation and commercial support options. 
Use Cases: 
• 
Web Applications: Both are widely used in web development, often alongside PHP. 
• 
Data Warehousing: Suitable for managing large datasets and complex queries.

Section 2: MySQL Docker Container

2) Setup MySQL 
 
We need MySQL up and running to create databases and tables. We will use a docker image for this 
purpose. Follow the steps below to initialize and run MySQL. 
 
1. Create a file called “docker-compose.yml” and copy the code below. 
>>> touch docker-compose.yml 
version: "3" 
 
services: 
 
  python-dev: 
    container_name: python-dev-container 
    build: 
      context: . 
      dockerfile: Dockerfile 
    volumes: 
      - ./test:/home 
 
  mysql-dev: 
    image: mysql:8.0 
    container_name: mysql-dev-container 
    ports: 
      - "6603:3306" 
    environment: 
      MYSQL_ROOT_PASSWORD: "root" 
    volumes: 
      - /storage/docker/mysql-datadirectory:/var/lib/mysql 
 
  adminer: 
    image: adminer 
    container_name: adminer-tool 
    restart: always 
    ports: 
      - "8080:8080" 
    depends_on: 
      - mysql-dev 
 
networks: 
  devnet: 
 
1. Open the terminal, then run the command below. 
 
docker-compose up -d 
This command will build and run the python-dev, mysql-dev, and adminer containers. The -d flag 
starts the containers in detached mode, meaning they will run in the terminal's background.  
 
Note: Make sure Docker Desktop is running.

Section 3: Database CRUD Operation 
 
1) Database 
 
According to the database documentation from OCI (Oracle Cloud Infrastructure), databases are 
organized collections of data stored electronically in a computer system. A database is usually controlled 
by a database management system (DBMS). The data and the DBMS, along with the associated 
applications, are called a database system, often shortened to just “database.” The DBMS is how 
programming languages can interact with the database using Application Programming Interface (API).

2) CRUD operation 
 
We will explore CRUD operation in the database. CRUD refers to the four operations: CREATE, READ, 
UPDATE, and DELETE, used to implement persistent storage applications like relational databases. 
 
• CREATE: The CREATE operation lets you create a new table. 
 
1. Click on the SQL Command. 
 
 
 
2. Copy the SQL statement below. 
 
CREATE TABLE employee ( 
    id int NOT NULL PRIMARY KEY, 
    name varchar(255) NOT NULL, 
    email varchar(255), 
    gender varchar(255), 
    designation varchar(255) 
); 
 
3. Click on the “Execute” button.

• READ: The READ statement returns records from a database table based on some search 
criteria/clauses. The READ operation can return all records and some or all fields depending upon 
selection criteria. 
 
1. Click on the SQL command and copy the SQL statement below.

FROM employee   
 
WHERE designation = 'Software Developer'
