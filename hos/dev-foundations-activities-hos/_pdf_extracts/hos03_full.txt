Key Concepts 
 
In this HOS, we will build a small project using Python. We will use Flask, a microframework for creating 
REST APIs, CRUD operations, and Postman. 
 
What is REST?   
REST (Representational State Transfer), or RESTful, is a popular architectural pattern that allows a 
system to reliably and predictably serve data to an external source, like a frontend. It enables different 
systems, written in entirely different technologies, to communicate with your system. It is programming 
language-agnostic, but you must adhere to standards to make the interoperability between various 
systems dependable. In simple terms, REST is an HTTP, preferably an HTTPS request like requesting a 
regular website, but with specific rules allowing for reliable and understandable data transfer.

6) Creating a REST Service - POST 
 
An HTTP verb is something you use implicitly with every page load and every form submission on the 
Internet. It is a mandatory part of every HTTP call. In REST, you use the verb explicitly to tell the backend 
system what the action will be. We are going to explore four HTTP protocols. 
• 
GET retrieves data from the system. 
• 
POST adds new data to the system. 
• 
PUT replaces/modifies an entry entirely in the system. 
• 
DELETE removes an entry from the system. 
 
We are creating a CRUD (Create, Read, Update, Delete) REST Service for students. In this CRUD operation, 
we will only be storing names and ages. Please note HTTP POST and PUT are interchangeable terms, and 
both protocols can serve the purpose of creation and updation. 
 
To create a new Student Record in the system, add the code below inside the app.py file. 
 
@app.route('/students', methods=['POST']) 
def post_students_details(): 
    try: 
        data = request.get_json()  
         
        if not data or "name" not in data or "age" not in data: 
            return jsonify({'message': 'Bad Request: Name and Age are required'}), 400 
         
        database[data["name"]] = data["age"] 
         
        return jsonify({'message': 'Student added successfully'}), 201 
         
    except Exception as e: 
        return jsonify({'message': f'Error saving object: {str(e)}'}), 500 
 
 
This code accepts the HTTP post request with the path 'Students.' It parses the student Json request and 
stores it in a temporary data structure. 
 
7) Reading a REST Service - GET 
 
The GET method retrieves information from the given server using a given URI. Requests using GET should 
only retrieve data and should have no other effect on the data. 
 
Use the following code to get records 
 
@app.route('/students/<Student_name>', methods=['GET']) 
def get_students_details(Student_name): 
    age = database.get(Student_name) 
     
    if age is None: 
        return jsonify({'message': 'Record Not Found'}), 404 
     
    return jsonify({ 
        'name': Student_name, 
        'age': age, 
        'message': 'Record Found' 
    }), 200 
 
This code snippet defines a route that accepts a student name as a parameter. It retrieves the 
corresponding student record from a database. If the student is not found, it returns a 404 error. If found, 
it returns the student's name and age in the response, along with a 200 status code indicating success.

8) Updating a REST Service - PUT 
 
Updating/Modifying the existing records is the common request, and HTTP PUT request is the most used 
protocol. 
 
Use the code below to update existing records. 
 
@app.route('/students', methods=['PUT']) 
def put_students_details(): 
    try: 
        data = request.get_json() 
         
        if not data or "name" not in data or "age" not in data: 
            return jsonify({'message': 'Bad Request: Name and Age are required'}), 400 
 
        if data["name"] not in database: 
             return jsonify({'message': 'Student not found, cannot update'}), 404 
 
        database[data["name"]] = data["age"] 
        return jsonify({'message': 'Student updated successfully'}), 200 
         
    except Exception as e: 
        return jsonify({'message': f'Error updating object: {str(e)}'}), 500 
 
This code defines a route /students that accepts PUT requests. It extracts the JSON data from the 
request, updates the database dictionary with the new student detail, and returns a success message 
with a status code of 200 if successful. If an error occurs during the process, it prints the error message 
to the console and returns a "Failed" message with a status code of 400. 
 
9) Deleting a REST Service - DELETE 
 
An HTTP request of this type is sent to remove the target resource from the server. Precisely what happens 
on the server's side, such as whether the space is reclaimed or the resource is instead just taken offline, 
is under the server's control, and how its environment has been configured. 
 
Use the following code 
 
@app.route('/students/<Student_name>', methods=['DELETE']) 
def delete_students_details(Student_name): 
    result = database.pop(Student_name, None) 
     
    if result is None: 
        return jsonify({'message': 'Record Not Found'}), 404 
         
    return jsonify({'message': 'Record deleted successfully'}), 200 
 
This code defines a DELETE endpoint for removing a student record. It retrieves the student name from 
the URL, then attempts to remove it from the 'database' list. If successful, it returns a 200 status code 
with a message. If the student name is not found in the list, it returns a 404 status code. For any other 
exceptions, it prints the error message and returns a 400 status code.
