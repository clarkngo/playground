Distributed File Storage (Dropbox-Style)

📁 The Objective

A user saves a 2GB video file in their synced folder. Uploading it as one giant blob is unreliable and wastes bandwidth when only a small part of the file changes. Your design must handle this efficiently.

Think about: What must happen to the file before it is sent to the server — and why? What service tracks what the file is, who owns it, and which pieces it consists of? Where do the actual file pieces get stored durably? Once the upload is complete, how do the user's other devices learn that a new version is available?
