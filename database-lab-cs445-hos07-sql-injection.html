Software Process Management: Experiencing & Managing SQL Injection

Instructions:

  1. Normal Login: Enter username alice and password alicepass in both forms.
  2. The Attack: In the Vulnerable form, enter admin' -- as the username and anything as the password.
  3. Observation: Watch the "Backend Query" box to see how the code is manipulated.

app_vulnerable.py

Uses string formatting (f-strings) to build queries. Highly susceptible to hacking.

SELECT * FROM users WHERE user = '' AND pass = '';

app_secure.py

Uses parameterized queries. This method treats user input strictly as data, not code.

SELECT * FROM users WHERE user = ? AND pass = ?;
