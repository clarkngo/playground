Message Queues & Worker Sizing

A queue decouples producers (who generate work) from consumers (workers who process it). If producers publish faster than workers can process, messages pile up — the queue depth grows. If workers are faster than producers, the queue drains and workers sit idle. Watch the live queue simulation react as you change rates.

🔑 Little's Law

The fundamental law of queuing: L = λW

  • L = average items in the system (queue + being processed)
  • λ = arrival rate (messages/second)
  • W = average time spent in system (queue wait + processing time)

If 1,000 msg/s arrive and each takes 0.2s: L = 1,000 × 0.2 = 200 messages always "in flight"

📊 When to Scale Workers
Queue depth = 0:Workers are keeping up perfectly — may be over-provisioned
Queue depth growing:Add workers immediately — lag compounds quickly
Queue depth unbounded:Processing rate will never catch up — urgent scaling needed
