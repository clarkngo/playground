Storage Estimation

Storage seems cheap — until you're Instagram storing 100M photos a day. The trick is thinking in multiples: how much per user × how many users × how long you keep it × replication factor. That innocent 2 KB user profile becomes petabytes at scale.

📦
Replication Factor

Data is never stored once. The industry standard is 3 copies (primary + 2 replicas). S3 uses 6+ copies across 3 AZs. More copies = higher durability + higher cost.

🎬
Metadata Matters

Don't forget metadata — IDs, timestamps, user references, indexes. A 2 MB photo also has ~500 B of metadata per entry. At 100M photos/day, that's 50 GB/day of metadata alone.
