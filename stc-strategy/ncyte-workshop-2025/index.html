02 Workshop Validated

Things STC is already doing or moving toward that this workshop independently confirmed as best practice.

Portfolio-based, project-heavy assessment — The grade weight flip (project 60%, final exam 10%) is the workshop’s central structural recommendation. STC is already moving toward portfolio-based assessment in BSAI. This workshop provides an additional, concrete rationale: the project is AI-resistant by design when it requires visible process, iteration, and judgment.
Interactive, hands-on course materials (HOS labs) — Module 5 of the workshop built interactive teaching tools: network simulators, cryptography tools, 3D flashcards. STC’s HOS lab infrastructure (ARP, DHCP, AES, RSA tools already in the playground) is exactly this model. The workshop validates the investment.
LLM comparison as a classroom activity — Module 2 and Module 3 both built toward hands-on LLM comparison. The workshop ran participants through ChatGPT, Claude, Copilot, Gemini, Grok, and Perplexity side by side. This mirrors the multi-AI comparison lab proposed from the Higher Education Summit. Two independent sources now point to the same exercise.
Claude as a preferred instructional design tool — The workshop specifically called out Claude for building interactive syllabi. STC already uses Claude extensively (it is the primary AI in the playground). This is a validation of the tool choice for faculty-facing design work.
Cybersecurity-grounded AI ethics — Module 7 treated AI ethics as a technical domain (C2PA, perplexity/burstiness, digital provenance). STC’s cybersecurity-adjacent programs are well positioned to deliver this framing — ethics as engineering, not just philosophy.
03 Gaps Surfaced
No formal CO-STAR or equivalent prompting framework in curriculum — CS445 and CS628 both involve AI-assisted work, but there is no documented, teachable prompting framework built into the course design. Students are left to develop prompting skills ad hoc. The workshop showed that CO-STAR can be taught in a single session and retained as a durable skill.
Workshop reference: Session IV, Module 3
No QTI-based dynamic quiz pipeline — The workshop demonstrated AI-generated quizzes exported as QTI for direct Canvas import. STC builds quizzes manually or through Canvas. A QTI generation pipeline using AI would allow instructors to create large, varied question banks quickly — particularly useful for BSAI certification-prep content (AI-900, CISM-adjacent).
Workshop reference: Module 4, Session V
No interactive syllabus in CS445 or CS628 — The workshop built interactive syllabi using Claude. STC’s course syllabi are static documents. An interactive syllabus — one students can query, explore, and navigate — is a low-cost, high-visibility improvement that also models the AI-first instructional design STC promotes.
Workshop reference: Module 4
Grade weights have not been formally reviewed in light of AI — The grade weight flip (project 60%, final exam 10%) is a deliberate structural response to AI. STC is moving toward portfolios, but the current grade distribution in CS445 and CS628 has not been formally reviewed and adjusted with this principle in mind.
Workshop reference: AI Policy session, Day 2
NotebookLM not yet used as a student support tool — The workshop highlighted NotebookLM for creating study guides, audio summaries, and interactive podcast-style review sessions. STC has not formally incorporated it into course support resources, despite it being free and directly usable with existing course materials.
Workshop reference: Day 2 tools demo
No digital provenance module in BSAI ethics content — C2PA and digital provenance are directly relevant to cybersecurity (content authentication, supply chain integrity, AI-generated media detection). BSAI has an ethics component, but it likely does not yet cover the technical standards that underpin content authenticity.

04 Mapped Opportunities
🌟
CO-STAR as a Taught Framework → CS445 and BSAI
From: Session IV, Module 3 — Building Effective Prompts
CO-STAR is teachable in a single session, memorable, and transferable across tools. More importantly, it is a pre-thinking discipline: it forces students to clarify Context, Objective, Style, Tone, Audience, and Response format before generating anything. For CS445 students who are already writing code with AI assistance, adding a structured prompting layer would immediately improve output quality. For BSAI, it could become the foundational framework for the entire prompting unit.
Add a CO-STAR prompting module to CS445 (as a HOS activity) and BSAI (as a standalone unit). Build a drag-and-drop activity in the playground where students assemble a CO-STAR prompt from components and see how each element changes the output.
⚖
Grade Weight Flip → Formal Review of CS445 and CS628 Grade Structure
From: AI Policy session — "AI OK / partial / not OK"
The workshop made a compelling structural argument: if the final exam is the highest-weighted item, students have a strong incentive to cheat on it. If the project is the highest-weighted item, AI use in the project is a feature (visible process, better output) rather than a threat. STC’s portfolio direction is aligned with this logic, but the actual grade weights in existing courses may not yet reflect it.
Review grade weight distributions in CS445 and CS628. Wherever a final exam carries more than 30% of the grade, propose a rebalancing toward project and portfolio work. Document the rationale for the AI committee as a policy recommendation.
📚
Interactive Syllabus Using Claude → CS445 and CS628
From: Module 4 — Instructional Design Using AI
The workshop demonstrated building an interactive syllabus using Claude — a document students can query conversationally rather than read linearly. Given that STC already builds interactive HTML tools in the playground for educational use, an interactive syllabus is a natural next step. It also models the AI-first design philosophy STC promotes: faculty who build interactive syllabi are demonstrating the very skill they want students to develop.
Build an interactive syllabus for CS628 in the playground using the existing dark-theme HTML component style. Students can browse by week, filter by topic, or ask natural-language questions about course expectations. Use Claude to generate initial content from the existing syllabus document.
⚙
QTI Quiz Generation Pipeline → BSAI Certification Prep
From: Module 4 — QTI Generation Prompt
AI can generate quiz questions in QTI XML format, which Canvas imports directly. For BSAI students working toward AI-900 or other certifications, a large, varied question bank is a significant study asset. Currently STC builds questions manually. A QTI pipeline — prompt Claude with learning objectives, receive a QTI file, import to Canvas — could produce a full practice quiz bank in minutes. It also makes it easy to update questions when certification exam content changes.
Build a QTI generation prompt template for the AI committee. Pilot with 20–30 AI-900 practice questions for BSAI. Import to Canvas and test the student experience. If successful, extend to CS445 and CS628 assessment banks.
🎧
NotebookLM Study Guides → All STC Courses
From: Day 2 tools demo — NotebookLM podcast and interactive audio
NotebookLM is free, requires no institutional setup, and works with any PDF or document. Faculty upload course materials and it generates a conversational audio summary that students can query interactively. For STC’s international students who process information better through audio, or who are intimidated by dense technical reading, this is a low-barrier support tool. It also reduces the load on faculty to produce supplemental explainers for every topic.
Pilot NotebookLM in one CS445 or CS628 module: upload the existing PDF cookbook and course slides, generate an Audio Overview, and share the link with students as an optional study resource. Collect feedback on usefulness before expanding.
🔐
Digital Provenance and C2PA → BSAI Ethics Module
From: Module 7 — Ethical AI Use in the Classroom
C2PA (Coalition for Content Provenance and Authenticity) is a cryptographic standard for embedding verifiable origin metadata into digital content. For cybersecurity-oriented students, this is directly relevant: content authentication, supply chain integrity, and AI-generated media detection are all active threat vectors. Adding C2PA and digital provenance to BSAI’s ethics module grounds AI ethics in a technical, verifiable standard rather than abstract principles — which is a more credible and more useful framing for this audience.
Add a digital provenance unit to the BSAI ethics module covering C2PA, IPTC metadata standards, and perplexity/burstiness as AI detection signals. Build a short interactive demo in the playground showing how C2PA metadata can be embedded and read.
👥
NCyTE Partnership → Curriculum Co-Development and Certification Alignment
From: Event context — CityU as NCyTE host institution
CityU hosted this NCyTE workshop. That relationship is an underutilized asset. NCyTE produces curriculum resources, certifications (CISM-aligned content, CMMC frameworks), and professional development specifically for technical college educators. STC could leverage this relationship to co-develop cybersecurity AI content, access NCyTE’s curriculum library, and potentially offer NCyTE-affiliated professional development to CityU faculty as part of the AI committee’s faculty support work.
Contact NCyTE to explore a formal curriculum partnership or co-development agreement. Specifically: access to NCyTE’s AI for cybersecurity educators curriculum, co-branding for future workshops hosted at CityU, and alignment between BSAI content and CISM/CMMC credential pathways.
05 Open Questions for STC
What are the current grade weight distributions in CS445 and CS628, and have they been reviewed with AI in mind?
The grade weight flip is the most immediately actionable idea from the workshop. Before implementing it, the current state needs to be documented. If final exams already carry less weight, the work may be partially done. If not, this is a clear gap with a clear fix.
Should CO-STAR be the official STC prompting framework, or should we evaluate alternatives (RISEN, RTF, Chain-of-Thought) before standardizing?
CO-STAR is teachable and memorable, but it is not the only framework. Standardizing too quickly on one approach could limit flexibility. However, having no standard means students in different courses develop incompatible mental models. This is a decision for the AI committee.
How do we use the NCyTE relationship proactively, rather than just as a hosting venue?
CityU hosted the workshop but may not have extracted institutional value from the relationship beyond the event itself. NCyTE has curriculum, certification alignment, and a network of technical college partners. What would a deeper partnership look like, and who at CityU should own it?
Is there an existing AI-900 or CISM-adjacent content library STC can draw from, or does it need to be built from scratch?
The QTI quiz pipeline is only valuable if there is a strong source of learning objectives to generate from. If BSAI already has alignment with AI-900 or CISM content areas, the question bank can be built quickly. If not, the objectives need to be defined first.
What is the right entry point for digital provenance in BSAI — ethics module, security module, or a standalone unit?
C2PA and digital provenance sit at the intersection of ethics, cybersecurity, and media literacy. Placing it in the wrong module could cause it to feel out of place. The right home depends on how BSAI’s curriculum is currently sequenced.
