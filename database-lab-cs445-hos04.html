SQL Guide

1. Create Table

CREATE TABLE employee (
    id int NOT NULL PRIMARY KEY,
    name varchar(255) NOT NULL,
    email varchar(255),
    gender varchar(255),
    designation varchar(255)
);

2. Insert Data

INSERT INTO employee (id, name, email, gender, designation) VALUES
(1, 'Alice', 'alice@xyz.com', 'M', 'Software Developer'),
(2, 'John', 'john@xyz.com', 'M', 'Software Manager'),
(3, 'Ajay', 'ajay@xyz.com', 'M', 'Software Developer'),
(4, 'Polina', 'polina@xyz.com', 'F', 'Sales Manager'),
(5, 'Henry', 'henry@xyz.com', 'M', 'Senior Software Manager');

3. Read Data

SELECT * FROM employee 
WHERE designation = 'Software Developer';

4. Update Data

UPDATE employee 
SET designation = 'Senior Software Developer' 
WHERE id = 1;

5. Find One

SELECT * FROM employee 
WHERE id = 1;

6. Delete One

DELETE FROM employee 
WHERE id = 3;

7. Verify

SELECT * FROM employee;

Command Explanations

CREATE TABLE Defines the table schema. id is the Primary Key, ensuring every employee has a unique identifier.
INSERT INTO Adds new records (rows) to the table. This populates your database with initial data for Alice, John, Ajay, Polina, and Henry.
SELECT (READ) The WHERE clause filters data. Step 3 retrieves only "Software Developers," while Step 5 targets a specific id.
UPDATE Modifies existing data. In Step 4, we change Alice's designation to promote her to a Senior role.
DELETE Permanently removes a record. Step 6 removes Ajay from the table using his unique id.
VERIFY A final SELECT * (Select All) shows the final state of the table after all your CRUD modifications.
