💡 Why it matters

The POODLE attack (2014) and numerous padding oracle attacks exploit exactly this pattern: CBC decryption without authentication. An attacker who can submit modified ciphertexts and observe whether the server returns a padding error can recover the full plaintext in O(256 × message_length) requests — no key required. In 2013 the Lucky13 attack demonstrated this against TLS 1.2. Fix: replace both functions with a single AES-GCM call — modes.GCM(iv) provides confidentiality and authentication in one primitive, or prepend an HMAC-SHA256 of the ciphertext before returning.
