💡 Why it matters

In 2017 a startup left AWS credentials in a public GitHub repository. An automated bot found and exploited the keys within 4 minutes, spinning up 140 EC2 instances and generating $6,000 in charges overnight. Thousands of live credentials are found in public repos each year via automated scanning tools like truffleHog and GitGuardian. Fix: store secrets in environment variables, AWS Secrets Manager, HashiCorp Vault, or a .env file excluded from version control. Rotate any key that has ever touched source code immediately.
