💡 Why it matters

Python's random module uses the Mersenne Twister algorithm, which is designed for statistical simulations — not security. After observing just 624 consecutive outputs, an attacker can reconstruct the entire internal state and predict every future value. For session tokens this means any active session can be forged. Fix: always use secrets.token_urlsafe(32) or os.urandom(32) for security-sensitive values. The secrets module was added to Python 3.6 precisely for this purpose.
