Risk Register
RiskSeverityProbabilityMitigation
Extreme class imbalance defeats the model
Owner: M3
 HighHigh Compute class weights from training labels and set weightCol. Use AUC-ROC (not accuracy) as CrossValidator metric. Tune decision threshold post-training. Report recall at multiple thresholds.
Dataset too large for local Spark setup
Owner: M1 / PM
 HighMedium Use Databricks Community Edition (free 15 GB cluster). If unavailable, work with a single manufacturer subset (Seagate only = ~34% of records). Cache aggressively and repartition by model to minimize shuffle cost.
Quarterly schema changes break union
Owner: M1
 HighHigh M1 loads each quarter separately and prints schema. Select only the intersection of columns present in ALL quarters. The 6 core SMART attributes (5, 9, 187, 188, 197, 198) are stable. Use Backblaze schema CSV to verify.
Label engineering window function logic error
Owner: M1 + M3
 HighMedium Test on a single serial_number with a known failure before applying to full dataset. Verify that the labeled row count makes sense: roughly 30x more rows labeled 1 than raw failure count (each failing drive contributes up to 30 positive rows).
Random train/test split causes data leakage
Owner: M3
 HighMedium Use temporal split only: filter by date, never by random sampling. This is a non-negotiable requirement for time-series data. Document in the paper why random split would inflate results artificially.
CrossValidator runtime too slow (large dataset)
Owner: M3
 MediumHigh Reduce to 3-fold CV and 4 parameter combinations (2 maxIter x 2 maxDepth). Cache the labeled DataFrame before CrossValidator. Run overnight if needed. Record wall-clock time as Chapter 7 demonstration.
SMART columns missing for many drive models
Owner: M1, M2
 MediumHigh Filling null SMART values with 0 is a reasonable imputation — absent attribute = no reported error. Document this choice explicitly in the paper. In EDA, count the null rate per SMART column per manufacturer as supporting evidence.
Paper does not clearly justify Spark over pandas
Owner: M4
 MediumMedium Include specific numbers: state the uncompressed file size (12+ GB/year), total row count, and number of distinct drives. Show that this exceeds single-machine memory capacity. Reference Spark distributed processing architecture explicitly.
