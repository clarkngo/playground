Risk Register
Risk Severity Probability Mitigation
M1 environment setup fails or delays
Owner: M1 / PM
 High Medium Agree on environment in kickoff sync. Use Databricks Community Edition as fallback — no local install needed. Timebox setup to 2 days max before escalating.
Class imbalance makes model appear good but F1 fails target
Owner: M3
 High High Use macro F1 (not accuracy) as primary metric from the start. Consider weightCol in RandomForestClassifier. Discuss RNF class inherent unpredictability in the paper rather than treating it as a model failure.
CrossValidator takes too long to run (45 model fits)
Owner: M3
 Medium High Cache the transformed DataFrame before CrossValidator (Chapter 7). Reduce grid: start with 4 combinations (2 numTrees × 2 maxDepth), expand if time allows. Run overnight if needed.
Paper exceeds 7 pages or falls short of 6
Owner: M4
 Medium Medium Set up EDSIG template in Week 1 and track page count early. Each section has a target page budget (see Paper Guide tab in the project page). Cut figures before cutting content.
M2 or M3 stuck waiting for M1 data handoff
Owner: M1 / PM
 Medium Medium M2 can begin query planning and figure design using a subset of the raw CSV directly. M3 can scaffold pipeline code using a dummy DataFrame. Both can merge M1 output later.
StringIndexer label encoding order differs across runs
Owner: M1, M3
 Medium Low M1 must document and share the exact label-to-index mapping from StringIndexer output. M3 must use the same fitted StringIndexer (not refit independently) when evaluating the model.
Team member unavailable during final week
Owner: PM / All
 High Low All deliverable notebooks must be committed to a shared repo or Databricks workspace by Week 5. No single member should hold sole access to any artifact.
AI4I dataset columns named differently than expected
Owner: M1
 Low Medium Print schema immediately after loading. The Kaggle version uses spaces in column names (e.g., "Air temperature [K]") — use backtick quoting in Spark SQL or rename columns in M1 cleaning step. Share renamed schema with the team.

  • Confirm EDSIG/CONISAR template location and page budget per section
