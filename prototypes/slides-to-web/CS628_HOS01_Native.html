Welcome to AI-Powered Web Development

In this hands-on skill exercise, you'll experience building and running a complete AI-powered web application. You'll work with modern web technologies including React for the frontend, Express for the backend, and Ollama with Gemma 2 for AI capabilities.

This tutorial will guide you through setting up a development environment and running your first intelligent chat application.

Technology Stack Overview

React provides a dynamic UI. Express connects the frontend to the LLM backend via APIs. Ollama hosts the Gemma 2 model, which powers the conversational AI. Together, these technologies create a seamless, responsive, and intelligent chat experience.

React: Frontend Framework

Modern JavaScript library for building user interfaces with component-based architecture and efficient virtual DOM.

Express: Backend Framework

Fast, unopinionated web framework for Node.js that handles API routes and server-side logic.

Ollama: LLM Host Management

Local LLM hosting solution that provides easy access to large language models without cloud dependencies.

Gemma 2: Advanced NLP Model

Google's state-of-the-art large language model designed for natural conversation and intelligent responses.

Section 2: Install and Run AI-Powered Web App

Step 1: Install and Start Ollama Server

First, we need to install Ollama, which will host our large language model locally.

curl -fsSL https://ollama.com/install.sh | sh
ollama serve

Step 2: Download the Gemma 2 Model

Open a new terminal window and download the Gemma 2 model (2B parameter version for efficient local execution).

ollama pull gemma2:2b
The model download may take several minutes depending on your internet connection. The 2B model is approximately 1.7GB in size.

Step 3: Start the Backend Server

Navigate to the backend directory and install dependencies, then start the Express server.

cd backend
npm install
node index.js
Port Configuration: After starting the backend server, make sure to set the port visibility to public in your Codespace settings to allow frontend communication.

Step 4: Test Backend Connection

Verify your backend server is running correctly by accessing the forwarded address. In the Ports tab, hover over Port 3001 and click the globe icon to open the backend endpoint.

You should see a "Hello World from Backend Server" message, confirming the server is operational.

Step 5: Start the Frontend React Server

Open another terminal window, navigate to the frontend directory, and start the React development server.

cd frontend
npm install
npm start

Testing Your Application

Interacting with Your AI Chat Interface

Access the Chat Interface

Once both servers are running, you can access the chat interface through the forwarded frontend port. The application provides a clean, modern chat interface where you can interact with the Gemma 2 language model.

Test the AI Functionality

Try sending various types of messages to test the AI capabilities:

  • Ask general knowledge questions
  • Request code explanations or examples
  • Engage in conversational dialogue
  • Test the model's understanding of context
Response Time: Local LLM responses may take 5-15 seconds depending on your system resources and query complexity. This is normal for local model inference.

Troubleshooting Common Issues

Backend Connection Issues

If the frontend cannot connect to the backend:

  • Verify the backend server is running (check terminal output)
  • Ensure port 3001 is set to public visibility
  • Check that Ollama service is running in the background

Model Loading Issues

If the AI model isn't responding:

  • Confirm the Gemma 2 model downloaded successfully
  • Restart the Ollama service if needed
  • Check system resources - the model requires adequate RAM

Frontend Issues

If the React app isn't loading:

  • Verify all npm dependencies installed correctly
  • Check the browser console for JavaScript errors
  • Ensure the development server is running on the correct port
