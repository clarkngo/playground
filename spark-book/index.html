How to use this supplement
📖
Read first
Skim the book chapter to get the vocabulary. Come here when a diagram feels static.
🎛️
Break things
Try the edge cases — OOM, zero partitions, 100% late events. That is where intuition forms.
💡
Read the log
Each interactive shows a live log. The messages match what you will see in Spark UI.
🔁
Re-run scenarios
Each chapter has 2–3 scenarios. Run all of them — differences between them teach more than the happy path.
