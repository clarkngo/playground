💡 Why it matters

ECB mode (Electronic Codebook) encrypts every 16-byte block independently with the same key. Identical plaintext blocks always produce identical ciphertext blocks — patterns leak through. This was famously demonstrated by encrypting the Linux mascot "Tux" — the encrypted image still clearly showed a penguin. ECB mode should never be used. Modern systems use AES-GCM or at minimum AES-CBC with a random IV.
