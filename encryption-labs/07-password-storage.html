Password Storage

Plaintext → MD5 → bcrypt — which matters when a database leaks

Scenario: A breach notification arrives — an e-commerce site's user database was posted on a hacking forum. Three companies stored passwords differently. Click the database that puts users at most immediate risk.

⚡ See how MD5 passwords are cracked instantly (rainbow table lookup)

Rainbow tables pre-compute millions of password hashes. A lookup takes microseconds — no brute force required.

💡 Why it matters

Password storage best practice: use a slow, salted hashing algorithm — bcrypt, scrypt, or Argon2. The unique random salt per password defeats rainbow tables. The deliberately slow computation (tunable cost factor) makes each guess expensive even with GPU clusters. NIST SP 800-63b mandates these requirements.
