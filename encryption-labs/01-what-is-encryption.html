What is Encryption?

Plaintext · Ciphertext · Keys — Caesar cipher hands-on

Scenario: A Roman general needs to send orders across enemy lines without the enemy understanding them. His solution — used by Julius Caesar around 58 BCE — is a simple key-based cipher. The same four concepts (plaintext, ciphertext, key, algorithm) power AES-256 today.

💡 Why it matters

Every encryption system — from Caesar to AES-256 — uses the same four concepts:

  • Plaintext — the original readable message
  • Ciphertext — the scrambled output that hides the meaning
  • Key — the secret that controls the transformation (shift = 3)
  • Algorithm — the agreed-upon method (shift each letter)

Without the key, ciphertext is meaningless noise. Modern encryption is exponentially harder to break — but the concept is identical.
