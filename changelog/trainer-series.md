### [feature] Trainer Series section created
- Hub page with whiteboard-drawing canvas animation, green/teal accent theme
- 10 interactive interview prep trainers across 4 sections: Classic Problems, Real-Time, Data-Intensive, Media & Scale
- Each trainer uses an 8-step interview walkthrough: Requirements → Capacity → API → Data Model → Architecture → Deep Dives → Trade-offs → Interview Tips
- Canvas-based animated architecture diagrams per trainer
